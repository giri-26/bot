# AI Chatbot 

An AI-powered chatbot built to explore local AI models and create a personal conversational assistant. This project helped me understand how AI models can be integrated into an application to provide interactive and intelligent responses.

I built this project as part of my journey into Artificial Intelligence, Large Language Models (LLMs), and application development.

##  About the Project

This project is a personal AI chatbot designed to provide a simple and interactive chat experience. It uses Ollama to run AI models locally, allowing users to communicate with an AI assistant through a conversational interface.

The main goal of this project was to gain practical experience working with AI models, application development, and the integration of AI capabilities into a usable application.

##  Features

* **AI-Powered Conversations:** Interact with an AI assistant and receive responses to your questions.
* **Local AI Model Integration:** Run supported AI models locally using Ollama.
* **Interactive Chat Interface:** Communicate with the chatbot through a user-friendly interface.
* **Response Regeneration:** Generate another response when you want a different answer.
* **Chat Management:** Manage conversations and clear chat history.
* **Conversation Experience:** Explore different ways of interacting with an AI assistant.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Python
* Ollama
* Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

### 2. Install Dependencies

If your project contains a `requirements.txt` file, run:

```bash
pip install -r requirements.txt
```

### 3. Set Up Ollama

Install Ollama and download a compatible model.

For example:

```bash
ollama pull llama3.2
```

Make sure the model name matches the model configured in your application.

### 4. Run the Application

Start the Ollama service if it is not already running.

Then execute your application's entry-point file. For example, if your main file is `app.py`:

```bash
python app.py
```

Open the local address displayed in the terminal if your application runs through a web server.

**Important:** The commands above are examples. Adjust them according to your project's actual files, dependencies, and configured model.
